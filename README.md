# MNU Pages

> «Our job is not to make things complex, but to make them simple and understandable.»

MNU Pages is a collection of simplified, human-readable documentation for CLI tools. These pages are designed to be **clear**, **calm**, and **actually helpful**.

## The Goal
Someone with basic knowledge should be able to read an MNU page once and say, "Oh… I get it now." The user may not master a tool but understand enough to freely use it.

## Available clients
- **Nodejs client**:
  ```bash
  npm i -g mnu-client
  ```
- **C Client (recommended)**:
  ```
  https://github.com/mnu-pages/mnu-client
  ```
